# Calculadora Básica em Python
Projeto simples desenvolvido em Python para realizar operações matemáticas básicas.

## Funcionalidades
- Soma
- Subtração
- Multiplicação
- Divisão

## Tecnologia
- Python

## Como executar
1. Execute o arquivo 'calculator.py'
2. Digite os números solicitados
3. Escolha a operação desejada
